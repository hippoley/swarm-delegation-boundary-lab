# Pre-sprint / sprint work boundary

## Before November 6, 2026

Allowed planning: research question, literature review, protocol, threat model, oracle specification, empty report structure, repository setup, environment checks. These are pre-existing assets and must be disclosed as such.

## During November 6–8, 2026

Record newly written simulator and policy code, scenario fixtures, run commands, raw outputs, evaluation, failure analysis, and final report. Preserve commit SHAs and timestamps. If any pre-existing code is reused, document the original source and scope of reuse.

## Evidence checklist

- Original commits and explicit reuse disclosure
- Frozen scenario/oracle version before comparisons
- Actual commands, environment, random seeds
- Raw outputs and checksums
- Independent verification of trace integrity claims
- Honest negative results, limitations and dual-use discussion
- Official report template and final submission confirmation

This document describes the proposed compliance boundary; consult the event's latest official rules before submitting.
